# 古文古诗学习馆

一个纯静态的初中文言文 / 古诗词学习网页，支持手机与电脑，双击 `index.html` 即可离线使用，也可在线访问。

## 在线访问

**https://yangxiaoran2014.github.io/guwen-hall/**

手机上直接打开这个链接即可（建议「添加到主屏幕」，用起来像 App）。学习数据保存在你各自设备的浏览器里，电脑和手机互不同步。

## 打开方式

- 线上：打开上面的链接。
- 本地：双击 `index.html`，或右键 → 打开方式 → 浏览器。

> 建议用 Chrome / Edge / Safari。语音朗读依赖浏览器自带的语音合成（中文语音需系统已安装）。
>
> 移动端：右上角 ☰ 展开导航；页面已适配刘海屏安全区、触控尺寸与横竖排诗文。

## 九个板块

| 板块 | 能做什么 |
| --- | --- |
| 学习地图 | 七大考点卡片（悬停有 3D 倾斜）、掌握度进度条、今日一诗 |
| 考点精讲 | 教材母题 → 答题思路（逐条浮现）→ 参考答案 → 答题公式（逐个点亮）→ 速记口诀（点击翻面）→ 必备知识 → 实战练习（七个考点共 **134 题**） |
| 断句工坊 | **长句断句（15 题，中考「限断 × 处」题型）** ＋ 基础短句（48 题）。在字与字之间点击生成「／」，一键检查：绿色=断对，红色=多断，金色闪烁=漏断，并提示多断/漏断数 |
| 自测问答 | 58 道主观题。先自己写答案 → 对照参考答案要点 → 自评「完全答对 / 答到一半 / 没答上」，进度自动记录 |
| 词义闪卡 | 143 张实词虚词卡，3D 翻转，按遗忘曲线（1/3/7/15/30 天）安排复习 |
| 随机闯关 | 从全部练习中随机抽 10 题，即时判分 + 结算动画 |
| 古诗文诵读 | 49 篇古诗文，逐句浮现，可切**竖排古籍版式**、听朗读、看注释与白话译文 |
| 背诵挑战 | 挖空背诵（点击空格揭示，三档难度）＋ 默写比对（LCS 逐字高亮对错） |

## 小技巧

- 右上角 🌙 切换夜间模式，🔊 开关音效。
- 闪卡页键盘：`←` `→` 切换，`空格` 翻面，`Esc` 停止朗读。
- 背诵默写时不要求标点，标点会被自动忽略后再逐字比对。
- 学习数据存在浏览器 localStorage，换浏览器 / 清理缓存会丢失，可在「我的进度」导出 JSON 备份。

## 内容来源

- 七大高频考点：整理自「高频考点」系列课件（划分朗读节奏、实词、虚词、翻译句子、断句、理解分析文章内容、拓展运用）。
- 古诗词正文：据部编版初中语文教材常见版本整理，并与公开资料（如「初中生必背古诗文 60 篇」）核对。
- 白话译文与注释为学习用参考，非教材原文，仅供理解。
