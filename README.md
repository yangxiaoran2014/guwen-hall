# 古文古诗学习馆

一个纯静态的初中文言文 / 古诗词学习网页，支持手机与电脑，双击 `index.html` 即可离线使用，也可在线访问。

## 在线访问

**https://yangxiaoran2014.github.io/guwen-hall/**

手机上直接打开即可（建议「添加到主屏幕」）。学习数据保存在各自设备的浏览器里，电脑与手机不同步。

## 打开方式

- 线上：打开上面的链接。
- 本地：双击 `index.html`。

> 建议用 Chrome / Edge / Safari。朗读依赖浏览器自带的语音合成（中文语音需系统已安装）。

## 版式与结构

整站按「书页」组织：左侧是线装书目录（手机上是抽屉式目录），右侧是正文页。正文只用细线与留白做分隔，不用卡片、阴影、渐变和装饰动效；动效只保留两处——断句落笔的斜杠、切页的轻微淡入。

七个考点按**五步**排序：

| 步 | 内容 | 对应考点 |
| --- | --- | --- |
| 一 读 | 先解决停顿，把句子读顺 | 划分朗读节奏 |
| 二 解 | 让每个字都有确定的意思 | 实词、虚词 |
| 三 断 | 给长句断句，标出停顿处 | 断句 |
| 四 译 | 把文言句译成现代汉语 | 翻译文言句子 |
| 五 答 | 从原文找依据，写出答案 | 理解分析文章内容、拓展运用 |

## 六个入口

| 入口 | 能做什么 |
| --- | --- |
| 功课 | 接着上次的地方继续；今日一诗；三个练习入口 |
| 学习路径 | 五步概览，点开任一考点看讲解 |
| 考点详情 | 教材母题 → 答题思路 → 参考答案 → 答题公式 → 口诀（点击翻面）→ 常见设问 → 必备知识 → 练习（七个考点共 134 题） |
| 断句练习 | 长句 15 道（中考「限断 × 处」题型）、短句 48 道；点字间空隙标停顿，检查后提示多断与漏断数 |
| 自测问答 | 58 道简答题；先自己写，再对照要点，自评三档 |
| 词义卡 | 143 张实词虚词卡，按 1 / 3 / 7 / 15 / 30 天间隔复习 |
| 随机练习 | 从全部练习里随机抽十道 |
| 诵读 / 背诵 | 49 篇古诗文，可切竖排；挖空背诵与默写逐字比对 |
| 记录 | 七考点进度、词卡与自测进度、错题本、导出与重置 |

## 小技巧

- 页脚左侧「音」「夜」：开关音效、切换日间/夜间。
- 词义卡键盘：`←` `→` 切换，`空格` 翻面，`Esc` 停止朗读。
- 默写不要求标点，比对时会先忽略标点。
- 数据存在 localStorage，可在「记录」导出 JSON 备份。

## 版本

- `v1-original` 标签：重构前的卡片流版本（渐变背景、花瓣、彩纸、圆环等），可随时用 `git checkout v1-original` 取回。
- 当前 `main`：书页版。

## 内容来源

- 七大高频考点：整理自「高频考点」系列课件（划分朗读节奏、实词、虚词、翻译句子、断句、理解分析文章内容、拓展运用）。
- 古诗词正文：据部编版初中语文教材常见版本整理，并与公开资料（如「初中生必背古诗文 60 篇」）核对。
- 白话译文与注释为学习用参考，非教材原文。
